# bananaOS

## Overview

**bananaOS** is a web-based operating system I built from the ground up for fun and to help me learn. It's built to run with minimal dependencies and be lightweight as possible while still being functional.

## Features

- Desktop environment
- Files app
- Terminal app with basic commands
- Text editor
- Photos editor
- Configurable settings

I have lots of other features and apps planned which will be added in the future. The project is open source and available on [GitHub](https://github.com/skbidisigma1/bananaOS).

## How to run

To run bananaOS locally, clone the repository and run `npm install` to install dependencies, then `npm run dev` to built the project. This will start a local development server which you can access in your browser at `http://localhost:5173`.

You can also access the webOS demo on [GitHub Pages](https://skbidisigma1.github.io/bananaOS).
